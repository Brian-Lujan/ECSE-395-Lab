# Lab 3 - Playing with Sensors

## Procedure 
I will uploading the code to the ESP32 through PlatformIO. I am using a Macbook Pro. 

In this repository, the code for the potentiometer reading can be found in 'src/potentiometer.cpp'. 

The code for output voltage measuring can be found in 'src/voltage.cpp'.

To implement these files:

1. Set up the ESP32 with all pins attached to a breadboard
2. Wire the potentiometer on the breadboard, connecting to the ESP32's VCC and ground, using pins A0-A5 as outputs.
3. Uncomment all of the code and adjust the baud rate to your system specs.
4. Build and upload the code.
